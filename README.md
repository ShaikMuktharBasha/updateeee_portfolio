# Shaik Mukthar Basha — Minimalist Developer Portfolio

An award-winning, editorial personal portfolio designed and engineered for **Shaik Mukthar Basha**, Computer Science student at KL University and full-stack software engineer.

Inspired by the design philosophies of **Apple**, **Linear**, **Vercel**, and modern **Swiss graphic design**.

---

## ✦ Design Philosophy & Core Principles

- **No Neon, No Futuristic Clutter**: Designed with intentional restraint, generous whitespace, and editorial typography.
- **Color Palette**:
  - Background: `#FAFAF8` (Off-white / Alabaster)
  - Primary Text: `#171717` (Deep Charcoal)
  - Secondary Text: `#737373` (Neutral Slate)
  - Accent: `#526B83` (Muted Steel Slate)
  - Architectural Hairline Borders: `#E8E8E5`
  - Cards: `#FFFFFF`
  - Full **Dark Mode** support (`#111214` background, `#18191C` cards, `#EDEDEC` text).
- **Custom Visual Previews**: Handcrafted micro-UI frames for every single project—zero broken external images or stock placeholders.
- **Performance**: Instantaneous load times, static asset compilation under 1 second, zero layout shifts.

## ✦ Technical Stack

- **Framework**: React 19 + TypeScript
- **Tooling**: Vite 8 + PostCSS + Tailwind CSS v4
- **Icons**: Lucide React + Bespoke SVG Brand Vectors
- **Animations**: Subtle CSS transitions & Framer Motion primitives
- **Deploy Ready**: Vercel / Netlify / GitHub Pages compatible
